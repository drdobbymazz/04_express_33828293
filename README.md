# Express Routing Project

Simple Express.js application with multiple routes.

## Setup

```bash
npm install
node index.js
```

Server runs on port 8000.

## Routes

- `/` - Home page
- `/about` - About page
- `/contact` - Contact info
- `/date` - Current date
- `/welcome/:name` - Welcome message (e.g., `/welcome/Ronald`)
- `/chain` - Chained handlers
- `/file` - Serves a.html

## Stop Server

Press `Ctrl + C`
